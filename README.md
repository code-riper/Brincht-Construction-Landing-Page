# 🏗️ Brincht Construction — Construction Company Website

Brincht Construction is a **responsive construction company website** designed to present information about a construction business, its services, company background, client testimonials, and contact details.

This project demonstrates my **practical frontend development skills** with a focus on creating a properly structured website using **semantic HTML5 elements**, responsive layouts, Bootstrap 5 components, custom CSS, and organized project files.

## 🧱 Semantic HTML5 Structure

One of the main objectives of this project was to practice creating a **properly structured webpage using semantic HTML5 elements**.

The website uses semantic elements such as:

```
<header>
<nav>
<main>
<section>
<footer>
```

These elements provide a meaningful structure to the webpage and make the code easier to understand, maintain, and organize.

The overall structure follows:

```
Header
  │
  ├── Navigation
  └── Hero Section
        │
        ▼
Main
  │
  ├── Services
  ├── About / Who Are We
  ├── Call to Action
  └── Client Testimonials
        │
        ▼
Footer
  │
  ├── Company Information
  ├── Useful Links
  ├── Contact Information
  └── Newsletter & Social Links
```
