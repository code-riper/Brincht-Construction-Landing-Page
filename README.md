# 🏗️ Brincht Construction — Construction Company Website

Brincht Construction is a **responsive construction company website** designed to present information about a construction business, its services, company background, client testimonials, and contact details.

This project demonstrates my **practical frontend development skills** with a focus on creating a properly structured website using **semantic HTML5 elements**, responsive layouts, Bootstrap 5 components, custom CSS, and organized project files.

---

## ✨ Features

* 🏗️ Construction company landing page
* 🏠 Hero section with company introduction
* 🔨 Services section
* 👷 About / company information section
* 💬 Client testimonials
* 🎠 Bootstrap testimonial carousel
* 📱 Responsive navigation
* 📋 Bootstrap Offcanvas mobile menu
* 📧 Contact information
* 📰 Newsletter subscription section
* 🔗 Social media links
* 📱 Responsive design for different screen sizes
* 🎨 Custom styling using CSS
* 🧩 Font Awesome icons

---

## 🧱 Semantic HTML5 Structure

One of the main objectives of this project was to practice creating a **properly structured webpage using semantic HTML5 elements**.

The website uses proper semantic elements.

These SEO tags provide a meaningful structure to the webpage and make the code easier to understand, maintain, and organize.

---

## 📱 Responsive Design

The website is designed to provide a responsive experience across:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

Bootstrap 5's responsive grid system is used to create flexible layouts.

This allows content to automatically adapt to different screen sizes.
